# Harsh Hospital Website

A static hospital website built with HTML, CSS, and JavaScript.

## Pages

- Home: `HTML/index.html`
- About: `HTML/About.html`
- Doctors: `HTML/Doctors.html`
- Services: `HTML/Services.html`
- Gallery: `HTML/Gallery.html`
- Appointments: `HTML/Appointment.html`
- Contact: `HTML/Contact.html`

The root `index.html` redirects visitors to the home page and is the GitHub Pages entry point.

## GitHub Pages

The intended public URL is:

`https://HarshSri1214.github.io/Harsh-Hospital-Website/`

Enable GitHub Pages for the `main` branch using the repository root as the publishing source.

## Contact form

The contact form currently contains a placeholder Web3Forms access key. Replace it with an access key from your Web3Forms account before expecting contact submissions to work. A key embedded in a static website is visible to visitors.

## Demo limitations

Appointment requests are stored in the visitor's browser using `localStorage`; they are not sent to hospital staff or stored in a shared database. Do not use this demo to handle real patient information.
